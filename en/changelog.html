Changelog

This site is not a one-shot static brochure — the data pipeline runs every day and the guides get deeper every week. This page records, in reverse chronological order, every change that affects your experience.

Scope

What this log covers — and what it doesn't

Covered: new pages, in-depth guide expansions, major data pipeline improvements, incidents and their fixes — each with what changed and why. Not covered: routine daily data updates (codes / weather / resource spots) — the pipeline runs silently 7 times a day, and the latest fetch time is shown right on the homepage data panel.

📮 Spotted a data error? Email contact@heartopiaguide.net — verified corrections are applied within 48 hours and noted on this page.
2026-09-30

Pipeline upgrade & content deep-dives

Pipeline🔄

7 fetches a day + scheduled audits

Fetch slots were expanded to 7 per day (06:10–23:30 Beijing time), plus 3 automatic audits (12:50 / 21:50 / 23:50). If a scheduled run is dropped by the platform, a retry is triggered immediately — codes no longer depend on precise cron timing.

Pipeline🎯

Codes moved to the comment API

After the official code moved into a post's comment section, the pipeline switched to the comment API and attributes each code by its publish time, auto-backfilling a rolling 14-day window — no more mistaking an old code for today's.

Content📈

Deep-dive analysis sections

Fishing "Fishery Economics", recipes "Profit Deep Dive", gifts "Favor Economics" and weather "The Weather Ledger" went live one by one — real in-game numbers to compute the opportunity cost of every activity, synced across zh / en / ja / ko.

Search🔍

Fishing page restructured

Every fish now gets its own heading (name + location + weather + time) plus FAQ structured data, matching "where to catch X" queries; page titles across languages were aligned with real search terms.

2026-09-21

Pipeline incident fix

Incident🛠️

Sept 18–21 outage post-mortem

Three stacked causes: a UTC-vs-Beijing timezone bug in scheduled runs, a gap in the weather calendar, and a stale code source. All missing data was backfilled, and self-checks were added so a silent failure can't happen again.
