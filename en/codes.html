FAQ

Code Redemption FAQ

Where do I enter Heartopia redemption codes?
In-game, open [Watch] → [Settings] → [Redeem Code], paste today's code copied from this page, and the reward lands in your in-game mailbox.
What time do codes update? How long are they valid?
Daily codes drop around 18:00 and are valid until 23:59:59 the same day. This page updates automatically via a data pipeline — no forum digging required.
Why does the page show "Update pending"?
The day's new code hasn't been posted yet, or the pipeline hasn't run (say you opened the page before 18:00). The page follows the homepage intel pipeline and updates itself — just refresh a bit later.
How many times can I gather Yo-yo Oak and Flawless Fluorite each day?
They reset at 06:00 daily — one gather per spot per day, 3 items each, with spots changing daily (usually near house entrances, in Spirit Oakpine Forest, or at Hot Spring Mountain Ruins). Gathering unlocks after the "Finding Star Spirits" main quest.
Where do I get the latest codes first?
Bookmark this page — it updates automatically every day. Data comes from multiple TapTap community sources; you can also check the original threads.
