更新履歴

この手帳は一度作って終わりの静的サイトではありません——データパイプラインは毎日走り、攻略は毎週深くなっています。このページでは、あなたの利用体験に影響する変更を新しい順に記録します。

記録方針

このログに載せるもの・載せないもの

載せるもの：新ページの公開、攻略の深化、データパイプラインの重要な改善、障害とその修正——何を・なぜ変えたのかを必ず添えます。載せないもの：毎日の定例データ更新（ギフトコード / 天気 / 採集スポット）。パイプラインは 1 日 7 回静かに走り、最新の取得時刻はホームのデータパネルに表示されます。

📮 データの誤りを見つけたら？contact@heartopiaguide.net までメールを。確認後 48 時間以内に修正し、このページにも記録します。

パイプライン強化と攻略の深掘り

パイプライン🔄

1 日 7 回取得 + 定時監査

取得枠を北京時間 06:10–23:30 の計 7 回に拡大し、さらに 1 日 3 回の自動監査（12:50 / 21:50 / 23:50）を追加。予約実行がプラットフォーム側で落ちた場合も即リトライし、コード更新が cron の遅延に左右されなくなりました。

パイプライン🎯

コード取得をコメント API へ移行

公式のコード発行場所が投稿のコメント欄へ移ったのに合わせ、コメント API に切り替えて投稿時刻で日付帰属。過去 14 日間の欠落も自動補填し、「古いコードを今日のものと取り違える」事故を根絶しました。

コンテンツ📈

攻略 4 ページに深掘り分析を追加

釣り「魚汛経済学」、レシピ「利益徹底計算」、プレゼント「好感度エコノミー」、天気「天気の損得勘定」を順次公開。実データで各プレイスタイルの機会費用を計算し、中 / 英 / 日 / 韓の 4 言語に同期しています。

検索最適化🔍

釣りページの構造化リニューアル

各魚を独立見出し（魚名 + 場所 + 天気 + 時間帯）に変更し FAQ 構造化データを追加、「〇〇はどこで釣れる？」系の検索にマッチ。各言語のページタイトルも実際の検索語に合わせました。
