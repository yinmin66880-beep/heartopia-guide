FAQ

쿠폰 코드 교환 FAQ

하트오피아 쿠폰 코드는 어디서 입력하나요?
게임 내에서 [시계] → [설정] → [쿠폰 코드]를 열고 이 페이지에서 복사한 오늘의 코드를 붙여넣으면 보상이 우편함으로 도착합니다.
코드는 몇 시에 갱신되나요? 유효기간은요?
데일리 코드는 매일 18:00경 발표되어 당일 23:59:59까지 유효합니다. 이 페이지는 데이터 파이프라인으로 자동 갱신됩니다 — 포럼을 뒤질 필요가 없어요.
페이지에 "갱신 대기 중"이라고 뜨는 이유는요?
오늘의 새 코드가 아직 올라오지 않았거나 파이프라인이 실행되지 않은 것입니다(예: 18:00 전에 페이지를 연 경우). 페이지는 홈의 정보 파이프라인을 따라 자동으로 따라잡습니다 — 조금 뒤에 새로고침해 보세요.
요요 오크와 무결점 형석은 하루에 몇 번 채집할 수 있나요?
매일 06:00에 초기화됩니다 — 포인트당 하루 1회, 회당 3개, 위치는 매일 달라집니다(주로 집 앞, 정령 참나무 숲, 온천산 유적 부근). 채집은 「별의 정령 찾기」 메인 퀘스트 완료 후 해금됩니다.
최신 코드를 가장 빨리 얻는 방법은요?
이 페이지를 즐겨찾기하세요 — 매일 자동 갱신됩니다. 데이터는 여러 TapTap 커뮤니티 소스에서 오며 원문 게시물도 확인할 수 있어요.
코드가 유효하지 않거나 만료되었다고 뜨면 어떻게 하나요?
먼저 날짜를 확인하세요: 데일리 코드는 당일 23:59:59까지만 유효합니다. '이미 사용됨'은 해당 계정이 이미 교환했다는 뜻이고(코드당 계정 1회), '유효하지 않음'은 대부분 직접 입력 실수 — 이 페이지의 '복사' 버튼으로 그대로 붙여넣으세요. 자세한 건 위의 교환 실패 트러블슈팅 표를 참고하세요.
데일리 코드 외에 받을 수 있는 코드가 있나요?
공식은 위챗 공식계정으로 주간 코드도 발표합니다; 설날·주년 기념·추석 등 시즌에는 여러 세트의 기념 코드가 나옵니다(보상은 달빛 수정·블루 다이아·한정 의상 등, 순서대로 누적 교환 가능). 과거 기념 코드는 위의 '기념 코드 아카이브'에서 확인하세요.
규칙

쿠폰 코드 규칙 상세 해설

데일리 코드, 주간 코드, 기념 코드는 저마다 규칙이 다릅니다 — 규칙을 알면 우편함을 헛되이 오가는 일이 없어요.

규칙 항목설명
🕐 발표 시간데일리 코드는 18:00경 발표(이 페이지 파이프라인은 18:10 / 18:40 / 23:30 세 번 수집해 커버); 데일리 자원 포인트는 06:00에 갱신
⏳ 유효 기간데일리 코드는 당일 23:59:59까지만 유효, 만료 후 폐기되고 다음 날 새 코드로 교체; 기념 코드의 유효 기간은 이벤트 공지 기준(보통 며칠~몇 주)
🔁 사용 횟수모든 코드는 계정당 1회만 사용 가능, 중복 입력 시 '이미 사용됨'으로 표시
🔤 대소문자데일리 코드는 7자리 영문+숫자 조합; 입력은 복사해서 붙여넣는 것을 권장 — 직접 입력 시 대소문자 착오나 공백 혼입이 잦습니다
📮 보상 지급교환 성공 시 보상은 게임 내 우편함으로 발송되니 꼭 수령하세요; 모든 것은 게임 내 실제 지급을 기준으로 합니다
🀄 코드 형태데일리 코드는 무작위 영문+숫자; 기념/주년 코드는 중국어 문구일 수 있습니다(예: '中秋月圆人团圆') — 표시된 그대로 입력하면 됩니다
💡 주간 코드와 기념 코드 — 데일리 코드 외에 공식은 위챗 공식계정으로 주간 코드를, 명절·주년 시즌에는 여러 장기 코드를 발표합니다(보상은 보통 데일리보다 후한 편 — 달빛 수정, 블루 다이아, 한정 의상 등). 아래 '기념 코드 아카이브'에 과거 대형 코드 기록을 남겨 둡니다.

날짜코드상태비고

교환이 안 된다면? 증상별 해결

교환 실패의 원인은 결국 네 가지뿐 — 표만 대조하면 30초 안에 문제가 보입니다.

메시지 / 증상원인해결 방법
코드가 만료되었다고 표시당일 23:59:59 경과당일 18:00 이후의 새 코드를, 이 페이지 상단에서 최신 것으로 복사
이미 사용되었다고 표시해당 계정이 이미 교환함(코드당 계정 1회)정상 현상 — 우편함에서 보상을 이미 받았는지 확인
코드가 유효하지 않다고 표시대소문자/문자 오타, 공백 혼입이 페이지의 '복사' 버튼으로 그대로 붙여넣기 — 직접 입력 금지
교환 성공했는데 보상이 없음우편함 미수령 / 네트워크 지연게임 내 우편함 확인; 여전히 없다면 게임 재시작 후 다시 확인
페이지에 표시된 코드가 교환 실패수집 이후 만료(날짜가 넘어간 뒤 오래된 캐시 열람)페이지를 새로고침해 날짜가 오늘인지 확인; 이 페이지는 매일 5회 자동 갱신됩니다
