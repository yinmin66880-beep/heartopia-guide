업데이트 로그

이 가이드는 한 번 만들고 끝나는 정적 사이트가 아닙니다 — 데이터 파이프라인은 매일 돌고, 공략은 매주 깊어집니다. 이 페이지는 이용 경험에 영향을 주는 모든 변경을 최신순으로 기록합니다.

기록 원칙

이 로그에 남기는 것, 남기지 않는 것

남기는 것: 새 페이지 출시, 공략 심화, 데이터 파이프라인의 주요 개선, 장애와 복구 — 무엇을 왜 바꿨는지 반드시 함께 적습니다. 남기지 않는 것: 매일의 정기 데이터 갱신(쿠폰 코드 / 날씨 / 채집 스팟). 파이프라인은 하루 7회 조용히 돌며, 최신 수집 시각은 홈 데이터 패널에 바로 표시됩니다.

하루 7회 수집 + 정기 감사

수집 시간대를 베이징 시간 06:10–23:30 총 7회로 확장하고, 하루 3회 자동 감사(12:50 / 21:50 / 23:50)를 추가했습니다. 예약 실행이 플랫폼에서 누락되면 즉시 재실행을 트리거해, 코드 업데이트가 cron 지연에 좌우되지 않습니다.

파이프라인🎯

코드 수집을 댓글 API로 전환

공식 발급처가 게시글 댓글창으로 옮겨감에 따라 댓글 API로 전환하고, 댓글 작성 시각 기준으로 날짜를 귀속시킵니다. 최근 14일의 누락도 자동 백필해 "오래된 코드를 오늘 것으로 착각"하는 사고를 원천 차단했습니다.

콘텐츠📈

공략 4개 페이지 심층 분석 추가

낚시 「어군 경제학」, 레시피 「이익 심층 계산」, 선물 「호감도 경제학」, 날씨 「날씨 수익 총장부」를 순차 공개. 실제 게임 데이터로 모든 플레이의 기회비용을 계산해 중 / 영 / 일 / 한국어 4개 언어에 동기화했습니다.
